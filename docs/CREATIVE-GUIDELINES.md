# Creative guidelines
Swiss editorial motion: typographic hierarchy, intentional negative space, asymmetric grid, monumental type, sharp visual contrast, deliberate timing. Colors carbon #151515, cream #F5F0E6, orange #FF6333. Fonts Space Grotesk and Inter, check licenses and proper font loading.
Avoid generic gradients, glow, excessive bounce, decorative shadows, stock-style UI. Every graphic element must express hierarchy, rhythm or transition.
